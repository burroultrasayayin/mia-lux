# Mia Lux website

This is a simple starter website for Mia Lux, a Lux Group brand. It is meant to be easy to open, read, and edit, even if you are new to GitHub.

The site is focused on sunglasses. It also includes the Mia Lux skincare masks, a wholesale section for Mia Skin beauty products, a short Miami tourism blog, a TikTok Shop page, and a link to the Mia Lux Facebook About page.

There are no prices anywhere in this project.

This is a Mia Lux site, not an Optique site.

## What you are looking at

A **repository** is a folder on GitHub that holds a project's files. This repository holds a small website made of ordinary web pages.

You do not need any special software to look at it. After you download the files, you can double-click `index.html` and it will open in your web browser.

## The pages

- `index.html` — the home page. This is the first page people see.
- `sunglasses.html` — the sunglasses showcase (the main focus of the site).
- `skincare.html` — the five Mia Lux face masks, with no prices.
- `wholesale.html` — wholesaling beauty products from Mia Skin, with no prices.
- `blog.html` — Miami Journal, a tourism blog with a few starter posts you can rewrite.
- `shop.html` — a TikTok Shop page. Add your real TikTok Shop link here when you have it.
- `styles.css` — the look of the site (colors, spacing, and fonts). You usually do not need to change this first.

## How the pieces connect

Every page uses the same header and footer so visitors can move around the site. The header includes a **Facebook About** link, which opens the About section of the Mia Lux Facebook page in a new tab:

https://www.facebook.com/profile.php?id=61582313002616&sk=about

The **TikTok Shop** page is a section ready for your shop. If you do not have a Mia Lux TikTok Shop link yet, leave the button as a placeholder and add the link later. Do not use a shop that belongs to another brand.

## How to add your TikTok Shop link

1. Open `shop.html` in any text editor.
2. Find the line that says `YOUR_TIKTOK_SHOP_LINK_HERE`.
3. Replace that phrase with your real TikTok Shop web address, and keep the quotation marks around it.
4. Save the file.

## How to edit the blog

Open `blog.html` and change the title or the paragraphs in any of the posts. To add a new post, copy one of the existing `<article class="post">...</article>` blocks and change the text inside it.

## How to change words on the site

Open the `.html` file you want to change, edit the sentence, and save. The page in your browser will show the new words after you refresh.

## What this project does not include yet

- It is not already published on a live web address of its own. GitHub can later host it with GitHub Pages, but that can wait until you are happy with the pages.
- It does not list prices.
- It does not automatically post to Facebook or TikTok. The Facebook and TikTok parts are links and a shop section for visitors to use.

## A short glossary

- **HTML file** — a web page. The name usually ends in `.html`.
- **CSS file** — instructions for how the pages should look. Here, that file is `styles.css`.
- **README** — this file. It is the note people see first when they open the repository on GitHub.
